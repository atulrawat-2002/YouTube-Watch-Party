# Watch Party Frontend

This is the frontend for the real-time YouTube Watch Party application.

## Features

- Join/Create room (creater of room becomes the host)
- Real-time video sync (play, pause, seek)
- Participants list
- Host / Moderator roles
- Remove participant
- State management with Zustand

## Tech Stack

- React
- Zustand
- Socket.IO Client
- YouTube IFrame API
